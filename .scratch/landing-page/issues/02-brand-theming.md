# 02 — Brand Theming & CSS Tokens

**What to build:** The scrollcraft CSS tokens are overridden with the coffee-beer brand palette. The page displays with warm brown canvas, cream text, gold accent, and proper typography hierarchy.

**Blocked by:** 01 (Project Setup)

**Status:** ready-for-agent

- [ ] Scrollcraft CSS tokens overridden in `globals.css`:
  - `--sc-canvas: #1a1410` (warm dark brown)
  - `--sc-surface: #2a2018` (surface)
  - `--sc-ink: #f5e6d3` (cream text)
  - `--sc-ink-soft: #a2968a` (secondary text)
  - `--sc-accent: #d4a017` (craft beer gold)
  - `--sc-accent-ink: #1a1410` (text on accent)
- [ ] Font display: Montserrat (headlines)
- [ ] Font text: Open Sans (body)
- [ ] Selection color, focus ring, scrollbar themed
- [ ] Page renders with correct colors and fonts
- [ ] Text contrast meets WCAG 2.1 AA (4.5:1 minimum)
